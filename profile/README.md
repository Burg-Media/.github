# Burg Media

Burg Media is a small web studio in the Netherlands. We build websites, web apps and custom software, and we give away the browser tools we make for our own work.

## Chrome extensions

Free, open source and private by design: no account, no analytics, no tracking, and the code is small enough to read yourself. Each repository explains every permission and everything that does or does not leave your browser.

| Extension | What it does | Source | Download |
|---|---|---|---|
| **Burg Analyzer** | See what a website runs on, with security header, SEO and speed checks | [burg-analyzer](https://github.com/Burg-Media/burg-analyzer) | [Release](https://github.com/Burg-Media/burg-analyzer/releases/latest) |
| **Burg Archive** | Save pages as one HTML or MHTML file, search and compare versions | [burg-archief](https://github.com/Burg-Media/burg-archief) | [Release](https://github.com/Burg-Media/burg-archief/releases/latest) |
| **Burg Color** | Eyedropper, page colors, WCAG contrast, gradients and palettes | [burg-color](https://github.com/Burg-Media/burg-color) | [Release](https://github.com/Burg-Media/burg-color/releases/latest) |
| **Burg Cookies** | Edit cookies and storage, decode JWTs, switch profiles, spot trackers | [burg-cookies](https://github.com/Burg-Media/burg-cookies) | [Release](https://github.com/Burg-Media/burg-cookies/releases/latest) |
| **Burg Focus** | Block distracting sites in focus sessions, on a schedule or by time budget | [burg-focus](https://github.com/Burg-Media/burg-focus) | [Release](https://github.com/Burg-Media/burg-focus/releases/latest) |
| **Burg Inspect** | Inspect fonts, sizes, spacing and CSS, with a ruler and grid overlay | [burg-inspect](https://github.com/Burg-Media/burg-inspect) | [Release](https://github.com/Burg-Media/burg-inspect/releases/latest) |
| **Burg Notes** | Quick notes from any page, linked to the site, stored on your device | [burg-notities](https://github.com/Burg-Media/burg-notities) | [Release](https://github.com/Burg-Media/burg-notities/releases/latest) |
| **Burg Screenshot** | Full page and area screenshots with PNG, JPG and PDF export | [burg-screenshot](https://github.com/Burg-Media/burg-screenshot) | [Release](https://github.com/Burg-Media/burg-screenshot/releases/latest) |
| **Burg Theme** | A dark Chrome theme in ink black and signal orange | [burg-theme](https://github.com/Burg-Media/burg-theme) | [Release](https://github.com/Burg-Media/burg-theme/releases/latest) |

Every extension is available in English and Dutch. For automatic updates, install them from the Chrome Web Store via [burgmedia.eu](https://burgmedia.eu); to run one from source, download the release zip and follow the steps in its README.

Burg Analyzer is licensed under GPL-3.0 because it includes Wappalyzer's detection engine and data; all other extensions are MIT.

Security or privacy problem? Email support@burgmedia.eu or use "Report a vulnerability" in the repository.
